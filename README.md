## 🧰 Run it yourself

```bash
npm install            # dependencies: serve, playwright
npm start              # live portfolio at http://localhost:3000
npm run setup          # one time: installs Chromium for recording
npm run record         # re-records assets/particles.gif + assets/tour.gif (needs ffmpeg)
```

- `index.html` is the full interactive portfolio (3D particle sphere, typing, tilt cards, glow).
- GitHub **Pages** deploys it automatically (`.github/workflows/pages.yml`).
- The **Record** workflow regenerates the README GIFs with Inter and Fira Code installed.
